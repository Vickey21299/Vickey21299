### About Me

I build **Generative AI and Agentic AI systems** focused on autonomous task execution, conversational interfaces, retrieval-augmented generation, and real-time voice interaction.

Currently working on enterprise AI automation and agentic workflows, with hands-on experience building **LLM-powered agents, RAG pipelines, tool orchestration, multilingual AI systems, and voice-based assistants**.

My recent projects include a **Real-Time Voice Scheduler AI Agent** and a **Voice-Based Farmer AI Agent**.

### AI & Engineering Focus

* **Agentic AI:** AI Agents, Tool Orchestration, Stateful Workflows, Agent Memory
* **Generative AI:** LLMs, Prompt Engineering, Structured Generation, LLM Evaluation
* **RAG:** Document Processing, Chunking, Embeddings, Vector Search, Context Retrieval
* **Conversational AI:** Voice Agents, Streaming Responses, STT/TTS, Multilingual AI
